# Веб-приложение с Bootstrap

## Описание проекта

Этот проект представляет собой простое веб-приложение:

1. Верстка прототипов страниц с использованием Bootstrap
2. Простое веб-приложение на Python, возвращающее HTML-страницы


## Структура проекта

### HTML-структура:

1. **Главная страница** (`main.html`)
2. **Категории** (`category.html`)
3. **Каталог/Заказы** (`catalog.html`)
4. **Контакты** (`contact.html`)

### Серверная часть:
   - Простой сервер на Python, который обрабатывает GET-запросы.

## Установка и запуск

### Клонируйте репозиторий

1. **Клонирование репозитория**:
   ```bash
   git clone <ссылка_на_репозиторий>
   cd <название_папки>
   ```

2. **Запуск веб-приложения**:
   - Убедитесь, что у вас установлен Python.
   - Запустите сервер с помощью команды:
   ```bash
    python main.py
    ```

3. **Проверка работы**:
   - Откройте браузер и перейдите по адресу `http://localhost:8000`.
   - Вы увидите страницу «Контакты».
